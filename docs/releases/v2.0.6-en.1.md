# Tigris 2.0.6-en.1

English build of [Tigris](https://github.com/lesnolie/Tigris) 2.0.6, published from the
`luumlabs` fork so that the English UI can auto-update on its own.

## What this is

- Full English translation of the UI: 296 strings hardcoded in Kotlin plus the 5 entries in
  `res/values/strings.xml`.
- Same launcher, same features, same MIT licence. Only the language changed.
- Upstream translation PR: https://github.com/lesnolie/Tigris/pull/31

## Auto-updates

Starting with this release, the built-in updater points at **this fork's releases** and verifies
that every update is signed with the same key as the installed app. Any later `*-en.N` tag
published here will be picked up automatically, about every six hours.

## Notes

- Signed with a fork key (`CN=Tigris EN`), so it cannot be installed over an official build and
  vice versa. Uninstall the other variant first.
- Not affiliated with the upstream author. If the translation is merged upstream, switch back to
  the official releases.
