# Tigris 2.1.0

First numeric release of the English fork, so the built-in updater can compare versions.

## Why the version scheme changed

The updater only accepts tags of the form `v<digits>(.<digits>)*`
(`UpdatePolicy`, regex `^v?(\d+(\.\d+){1,3})$`). The earlier `v2.0.6-en.1` /
`v2.0.6-en.2` tags were rejected as "not a version", so automatic updates could never fire.
From now on this fork uses plain numeric versions starting at `2.1.0`.

## Changes since 2.0.6

- Full English translation of the UI (296 Kotlin strings + 5 resources).
- Updater points at `luumlabs/Tigris` releases and verifies the fork signature.
- Fixed the `Auto update` row label losing its spacing.

## Install

Same fork key as the previous builds, so it upgrades in place when coming from another
fork build. Coming from an official Tigris build, uninstall first (different signature).
